# Cesium Worldbox roadmap

## Open


## Done

- Cesium globe, SGP4 satellite catalog, time simulation, 2D/3D, catalog filters
- Minimizable catalog panel
- Modular 3D layer system (ion optional)
- Live aircraft ADS-B layer
- Object thumbnails
- Weather layers, legends, opacity, units, weather time
- Selected Object panel hidden when nothing is selected
- Aircraft: zoom scaling, declutter, altitude line, estimated altitude, routes, airport markers
- Maritime: Ships / AIS layer (Baltic via Digitraffic), vessel details, ship pictures

- Layers: Space (satellites on/off + children), Transportation (airports, ports, flight routes, shipping lanes), Map labels (borders, capitals, states, cities)

## Later

- Shipping Traffic Density raster layer (World Bank AIS density)
- 10m-detail borders for very close zoom

- Animated radar history frames
- Marine wave height (needs an openly licensed source)
